# Condutor — GitHub Pages

Site completo em HTML e CSS. As imagens estão na pasta assets.
Não precisa instalar programas, compilar ou usar Node.js.

## Publicar
1. Extraia este ZIP no computador. Não envie o ZIP compactado para o repositório.
2. Crie um repositório público no GitHub ou abra o repositório onde deseja publicar.
3. Use Add file > Upload files e envie index.html, style.css e a pasta assets inteira. Inclua também .nojekyll, se visível. Confirme em Commit changes.
4. O index.html deve ficar diretamente na raiz do repositório, ao lado de style.css e assets, sem uma pasta adicional envolvendo tudo.
5. Em Settings > Pages, selecione Deploy from a branch. Escolha main e /(root), depois Save.
6. Aguarde a publicação. O endereço aparecerá em Settings > Pages.

## Editar
- index.html: textos, links e estrutura.
- style.css: cores, tamanhos, espaçamentos e animações.
- assets/: imagens e logos. Preserve os nomes ou atualize as referências no HTML.

Para visualizar no computador, abra index.html no navegador.
Se alguma imagem não aparecer no GitHub Pages, confira se a pasta assets foi enviada e se os nomes mantêm as mesmas letras maiúsculas e minúsculas.

Documentação: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
